# Джарвис

Автономный голосовой помощник для Windows. Работает локально: распознавание речи
происходит на компьютере, команды выполняются по правилам. Ни облачных сервисов,
ни Python, ни интернет-соединения для основных команд не нужно — сеть требуется
только для погоды и курса валют.

## Что нужно

- Windows 10/11 x64
- Микрофон
- Больше ничего: готовая сборка самодостаточная, .NET ставить не нужно

## Установка

Готовые файлы — в разделе [Releases](../../releases):

| Файл | Что это |
| --- | --- |
| `Jarvis-Setup.exe` | установщик, права администратора не нужны |
| `Jarvis.exe` | один самодостаточный файл, можно запускать откуда угодно |

Установщик ставит программу в профиль пользователя:

- программа: `%LOCALAPPDATA%\Programs\Jarvis`
- ярлык на рабочем столе: `Джарвис`
- меню «Пуск»: папка `Джарвис` (запуск и удаление)
- удаление: «Параметры → Приложения» или `uninstall.exe` в папке программы

При обновлении поверх старой версии `config.json` сохраняется.

Портативный вариант: скопируйте `Jarvis.exe` в любую папку и запустите.
Модель распознавания и иконка уже внутри, рядом ничего не нужно. Настройки при
первом сохранении появятся рядом в `config.json`.

## Первый запуск

Первый запуск показывает окно. Дальше приложение живёт в трее.

- **Num9** — удерживай и говори, отпусти — команда выполнится
- **Num8** — показать/спрятать окно
- Клавиши меняются в настройках

Закрытие окна крестиком прячет его в трей, а не закрывает приложение.
Выход — через меню трея.

## Команды

| Что | Примеры |
| --- | --- |
| Программы | «открой хром», «запусти стим», «открой телеграм» |
| Сайты | «открой ютуб», «открой вк», «открой авито» |
| Папки | «открой загрузки», «открой документы», «открой рабочий стол» |
| Звук | «громче», «тише», «громкость 40», «выключи звук», «включи звук» |
| Яркость | «ярче», «темнее», «яркость 70» (если монитор поддерживает DDC/CI) |
| Таймеры | «таймер на 10 минут», «отмени таймер» |
| Напоминания | «напомни через час позвонить», «напомни в 18:30 выключить плиту» |
| Система | «скриншот», «заблокируй компьютер», «спящий режим», «выключи компьютер», «перезагрузи компьютер», «отмена» |
| Окна | «закрой окно», «сверни окна», «переключи окно» |
| Медиа | «пауза», «следующий трек», «предыдущий трек», «останови музыку» |
| Справка | «который час», «какая сегодня дата», «какой день недели» |
| Погода | «какая погода», «погода в Питере» |
| Валюта | «курс доллара», «курс евро», «курс валют» |
| Калькулятор | «сколько будет 15 плюс 7», «двадцать умножить на три», «15 процентов от 200» |
| Ввод текста | «вставь привет мир» — напечатает в активное окно |
| Служебное | «что ты умеешь», «повтори», «очисти чат», «выход» |

Выключение и перезагрузка выполняются с задержкой 30 секунд (настраивается).
В течение этого времени команда «отмена» отменяет действие.

## Настройки

Кнопка «Настройки» или пункт в меню трея:

- модель распознавания: встроенная `base` или внешняя из папки `model`
- клавиши «говорить» и «окно»
- город для погоды
- задержка выключения
- автоматическое выполнение распознанного

Настройки лежат в `config.json` рядом с `Jarvis.exe`.

Модель распознавания встроена в программу. Чтобы попробовать другую, положите
`ggml-*.bin` в папку `model` рядом с `Jarvis.exe` и выберите её в настройках —
файл из папки имеет приоритет над встроенным.

## Свои программы

Встроенный список рассчитан на стандартные места установки. Если программа лежит
в другом месте, добавьте её в `config.json` — пересобирать ничего не нужно:

```json
{
  "extraApps": [
    {
      "name": "Telegram",
      "path": "%APPDATA%\\Telegram Desktop\\Telegram.exe",
      "keys": ["телеграм", "телега", "telegram"]
    },
    {
      "name": "Мой лаунчер",
      "path": "D:\\Games\\Launcher\\launcher.exe",
      "keys": ["лаунчер", "launcher"]
    }
  ]
}
```

`keys` — слова, по которым Джарвис узнаёт программу. Переменные вида `%APPDATA%`
раскрываются. Свои записи проверяются после встроенных, так что можно
переопределить и стандартное приложение.

## Как это устроено

- `SttEngine.cs` — запись микрофона (NAudio/WASAPI) и распознавание (Whisper.net);
  модель берётся из папки `model` или из ресурса внутри сборки
- `NativeRuntime.cs` — для сборки одним файлом: находит распакованные нативные
  библиотеки Whisper в `%TEMP%\.net\Jarvis\<hash>` и указывает их загрузчику
- `Parser.cs` — разбор команд: списки приложений, сайтов, папок, числа, время, длительность
- `MainForm.cs` — окно, трей, горячие клавиши, выполнение команд
- `Audio.cs` — громкость и mute через CoreAudio
- `Brightness.cs` — яркость через DDC/CI
- `InputSim.cs` — медиа-клавиши, Alt+F4, Win+D, Alt+Tab, Ctrl+V
- `SystemActions.cs` — блокировка, сон, выключение, скриншот, буфер обмена
- `WebTools.cs` — погода (wttr.in, запасной Open-Meteo) и курс ЦБ
- `Calc.cs` — калькулятор
- `Reminders.cs` — таймеры и напоминания
- `installer\Jarvis.nsi` — сценарий установщика NSIS

Чтобы добавить программу или сайт в встроенный список, допишите строку в таблицу
`Apps` или `Sites` в `Parser.cs` и пересоберите.

## Сборка из исходников

Нужен только [.NET SDK 10](https://dotnet.microsoft.com/download).

1. Скачайте модель распознавания
   [`ggml-base-q5_1.bin`](https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-base-q5_1.bin)
   (~57 МБ) и положите в папку `model`:

   ```
   model\ggml-base-q5_1.bin
   ```

   Модель не хранится в репозитории — это большой бинарный файл.

2. Соберите:

   ```
   powershell -ExecutionPolicy Bypass -File "Собрать-Джарвиса.ps1"
   ```

   Получится папка `publish` (exe + dll + модель).

   Один самодостаточный файл `dist\Jarvis.exe` (модель и иконка внутри):

   ```
   powershell -ExecutionPolicy Bypass -File "Собрать-Джарвиса.ps1" -SingleFile
   ```

   Установка из папки сборки в профиль и запуск:

   ```
   powershell -ExecutionPolicy Bypass -File "Собрать-Джарвиса.ps1" -Install -Run
   ```

3. Установщик `dist\Jarvis-Setup.exe`:

   ```
   powershell -ExecutionPolicy Bypass -File "Собрать-установщик.ps1"
   ```

   Скрипт сам собирает одиночный exe, один раз скачивает portable NSIS в
   `%LOCALAPPDATA%\JarvisBuild\nsis-3.10` и компилирует установщик. Если рядом с
   проектом есть `publish\config.json`, он попадает в установщик как настройки
   по умолчанию (при обновлении существующий конфиг не перезаписывается).
   Флаг `-NoConfig` собирает установщик без настроек по умолчанию.

## Диагностика

```
Jarvis.exe --selftest                  # отчёт в %TEMP%\jarvis-selftest.txt
Jarvis.exe --parse "открой ютуб"       # разбор команды в %TEMP%\jarvis-parse.txt
Jarvis.exe --stt-file test.wav         # распознать wav в %TEMP%\jarvis-stt.txt
```

`--selftest` проверяет звук, яркость, скриншот, буфер обмена, загрузку модели,
погоду, курс, калькулятор и парсер. В отчёте видно, взята модель из папки или
из самой программы.

## Ограничения

- Понимаются только известные команды. На свободные вопросы ответа нет — это не ИИ.
- Управление яркостью работает не на всех мониторах (нужна поддержка DDC/CI).
- Погода и курс валют требуют интернета; остальное работает офлайн.
- Распознавание на модели `base` иногда путает редкие слова — помогает `small`.
